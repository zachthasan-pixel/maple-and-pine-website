# Hasan Publishing — design brief

- **Design read** — A working independent press in Tokyo presenting its catalog to readers, reviewers, and prospective authors; the register is quiet confidence: a small house with the production polish of a large one.
- **Concept spine** — "The imprint page of a well-made book": the site reads like the front matter of a hardcover — cream paper, ink type, a single brick-red accent used the way a printer uses a second ink.
- **Delivery tier** — `editorial` (user's explicit choice: the client approved a static, typography-led mockup of this exact design before the build and delegated remaining choices; calm bookish craft, micro-motion only).
- **Locked palette** — `#1c1a17` ink, `#faf7f1` cream paper, `#f3eee4` parchment, `#8c2f22` brick red (single accent, used as a printer's second ink), `#b08d47` old gold (rules and small marks), `#e2dcce` hairlines. Defense: this is the USER'S OWN approved brand — the client signed off on a rendered mockup in exactly these hexes before the build began, which overrides palette-family guidance.
- **Locked type** — Iowan Old Style / Palatino / Georgia serif stack for display and body (bookish, matches the imprint's printed books); system sans for eyebrows, nav, buttons, and metadata. Serif justification: the brand IS a book publisher; the type must read as book typography.
- **Animation mode**: non-animated — user picked Non-animated at intake (the client approved a static design mockup of this site and answered follow-up option questions with "as long as it is clear, any of these options will do", delegating the call; a scroll-film treatment would contradict the approved design). Craft floor held via bespoke assets (real book cover art, composed OG plate, drawn placeholder covers), full bespoke chrome, and mount-time micro-motion (fade-rise on main, hover lifts on cards, per-CTA hover identities).
- **Section plan (home)** — 1. Hero: split ink-gradient stage, new release + tilted physical cover (family: split stage). 2. From Our Catalog: 4-up cover grid (family: card grid). 3. Imprint strip: dark 3-column facts band (family: stat band). 4. Newsletter: centered parchment band with inline form (family: centered call). No consecutive repeats; 4 families / 4 sections. Eyebrow budget: 2 ("New from Hasan Publishing", page-head kickers).
- **Pages** — Home, Books (filterable catalog), The Arab Dilemma (title page with metadata rail + buy links), About (story + founder card), Submissions (guidelines + working query form).
- **Asset plan** — Real cover art for The Arab Dilemma (client's own file); two art-directed CSS cover plates for the children's titles (sky-glider gradient; forest-web gradient) until real art arrives; composed 3:2 OG plate (wordmark + physical cover on cream); HP monogram favicon (brick tile, cream serif); no stock imagery anywhere.
- **CTA inventory** — `About the Book` (solid brick, lightens on hover), `View All Titles` (ghost hairline on ink, brightens), `Browse Catalog` (brick tab in nav), `Buy on Amazon` (brick outline that fills), `Subscribe` (solid brick pill-adjacent), `Submit Query` (full-width brick bar with press state). Each is its own component-level style; no shared button utility class.
- **Backend** — D1: `newsletter_signups` (unique email) + `manuscript_submissions`; two server functions; forms give inline confirmation. No auth, no Higgsfield integration.
